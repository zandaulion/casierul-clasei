# First-run example (synthetic)

To explore the app without entering school or family information, create a
throwaway class with these invented labels:

- School: `Școala Exemplu`
- Class: `Clasa Demo`
- School year: `2026–2027`
- Child entry: `Exemplu; Unu`
- Expense: `Materiale demonstrative`, 20 lei, due next month

Leave the payment-link, beneficiary, IBAN, WhatsApp contact, school logo and
attachment fields empty. The release contains no database, student list or
payment details. Delete the disposable Compose volume when you are finished
with this example; never use `docker compose down -v` on a real installation.
